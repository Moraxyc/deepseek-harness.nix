## クイックスタート

TUI プリセットを試します：

```sh
nix run github:moraxyc/deepseek-harness.nix#presets.tui \
  --accept-flake-config
```

`--accept-flake-config` フラグを指定すると、必要に応じてリポジトリに設定されたバイナリキャッシュを Nix が使用できるようになります。

## リモート flake を使用する

GitHub から個々の出力を直接実行またはビルドします：

```sh
nix run github:moraxyc/deepseek-harness.nix#default -- --version
nix build github:moraxyc/deepseek-harness.nix#dsh
nix build github:moraxyc/deepseek-harness.nix#dsh-desktop
nix build github:moraxyc/deepseek-harness.nix#dsh-desktop-official
nix build github:moraxyc/deepseek-harness.nix#dsh-kernel
nix build github:moraxyc/deepseek-harness.nix#dsh-workspace
nix build github:moraxyc/deepseek-harness.nix#bundles.tui
nix run github:moraxyc/deepseek-harness.nix#presets.tui
```

主な出力は次のとおりです。

| 出力                     | 用途                                                     |
| ------------------------ | -------------------------------------------------------- |
| `dsh`                    | CLI パッケージ                                           |
| `dsh-desktop`            | デスクトップアプリケーション                             |
| `dsh-desktop-official`   | 上流リリースのデスクトップアプリケーション               |
| `dsh-desktop-unofficial` | サードパーティプロジェクトのデスクトップアプリケーション |
| `dsh-kernel`             | プロファイルバンドルを含まないカーネル                   |
| `dsh-workspace`          | ビルド済みワークスペース成果物                           |
| `bundles.*`              | プラグイン形式の拡張機能                                 |
| `presets.*`              | すぐに使えるバンドルの組み合わせ                         |

完全な一覧は、[バンドルとプリセット](../catalog/)のカタログを参照してください。

`dsh-desktop` は `dsh-desktop-official` のエイリアスです。
`dsh-desktop-unofficial` も引き続きサポートされ、明示的に選択できます。
バリアントのソース、サポート対象プラットフォーム、`dshHost` オーバーライドについては、
[高度な使用方法](../advanced-usage/)を参照してください。

## 別の flake に追加する

リポジトリを入力として宣言し、そのパッケージ、モジュール、オーバーレイに `inputs.deepseek-harness.*` を使用します：

```nix
{
  inputs.deepseek-harness.url = "github:moraxyc/deepseek-harness.nix";
}
```

入力を宣言したら、[NixOS との統合](../nixos/)、[Home Manager との統合](../home-manager/)、または[高度な使用方法](../advanced-usage/)のガイドに進んでください。

## Cachix

公開キャッシュは次のコマンドで使用します：

```sh
cachix use deepseek-harness-nix
```

または、Nix の設定に手動で追加します：

```nix
{
  nix.settings = {
    substituters = [ "https://deepseek-harness-nix.cachix.org" ];
    trusted-public-keys = [
      "deepseek-harness-nix.cachix.org-1:5NrkwLN9veNMhiINtU5ZeV4isXFhFsOwn6Ms7J1M+TA="
    ];
  };
}
```
