# Bundles and Presets

This catalog is generated from the flake. Do not edit this file by hand.

Bundles are building blocks — pick the ones you need and combine them into
your own setup. For example, add bundles to an existing preset with
`pkgs.dsh.presets.web-ui.override { extraPlugins = [ pkgs.dsh.bundles.tui ]; }`,
or declare a custom profile with `programs.dsh.profiles.mine.bundles = [ ... ]`.
See the [README](../README.en.md) for details.
